# fitness_app · 健身小程序（纯空手版）

一个不用器械、在家就能练的上半身训练网页应用。打开就能用，不用装任何东西，不用注册，数据只存在你自己的浏览器里。

## 这是啥

- **纯空手**：所有动作只用地板和自重，不靠桌椅、不拿毛巾，连墙都默认不用（另有可选的「墙面模式」）
- **练上半身**：胸、背、肩、肱二头、肱三头、核心，目标是薄肌线条；斜方肌不设专项
- **动作都是经典动作**：标准俯卧撑、派克俯卧撑、超人式、平板支撑……全是健身圈公认的老牌动作，没有自创的野路子

## 功能

- **动作库**：18 个动作，每个带图解和一句大白话口诀；图解默认静止，鼠标悬停（手机点一下）才动。标准俯卧撑、派克俯卧撑、超人式、平板支撑已配真人示范照片（同一位男生模特，左右双格：起始 / 发力），其余动作暂时用手绘 SVG 两帧图解，之后会分批换成真人图
- **全自选**：肌群可多选过滤；器械模式可切（纯空手 / 纯空手+墙面）
- **我的计划**：把动作加进计划，自己调组数，自己选每周哪几天练
- **训练打卡**：训练日自动生成当日课表，做完一组点亮一组，结束一键打卡
- **记录**：累计训练次数、本周次数、累计组数，历史一目了然
- 数据用浏览器 localStorage 保存在本地，换浏览器/清缓存会清空，介意的话别清

## 怎么打开

1. 把这个仓库下载下来（Code → Download ZIP，解压）
2. 双击 `index.html`，用浏览器打开就能练

想给别人在线用的话：仓库 Settings → Pages → 选 main 分支，就能生成一个免费网址（GitHub Pages）。

## 文件结构

| 文件 | 干啥的 |
| --- | --- |
| `index.html` | 页面骨架 |
| `style.css` | 样式 |
| `exercises.js` | 动作库数据：动作、口诀、图解坐标都在这，想加动作改这个文件 |
| `app.js` | 全部逻辑：筛选、计划、打卡、记录 |
| `img/` | 真人示范图（双格照片，左边起始、右边发力） |

手绘图解是纯 SVG 线条小人（起始帧 / 发力帧两张图，悬停切换）；真人图在 `img/` 里，动作数据里配了 `img` 字段的优先显示真人图。整个项目没有任何第三方依赖。

## 加新动作

在 `exercises.js` 的 `EXERCISES` 数组里照着现有格式加一条：写清名字、肌群、组数次数、口诀，再给两帧小人坐标就行。坐标系是 200×120，地面在 y=104。
